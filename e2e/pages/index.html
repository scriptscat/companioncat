The event loop, explained

JavaScript runs one task at a time. When the call stack is empty, the event loop picks the next task from the queue.

Promises schedule microtasks, which always run before the next macrotask begins.

Rendering happens between tasks, so long tasks make the page feel slow.

A timer callback never runs earlier than its delay, only later.

事件循环每次只处理一个任务，调用栈清空后才会取下一个任务。
